# X-Ray Wave Nature (Ch.2 §5)

Bragg diffraction: X-rays interfere from crystal planes when nλ = 2d sin θ.

## Principle
Constructive reflection when path difference equals an integer number of
wavelengths — foundation of X-ray crystallography.

## The AI — discovers crystal spacing d
Grid search on d from noisy Bragg (n, λ, θ) measurements.

- `physics.js` — Bragg helpers (shared `../xray/physics.js`)
- `fit.js` — BraggSpacingFitter
- `module.js` — 2D Bragg canvas
